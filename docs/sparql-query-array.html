SPARQL-array redline of the SPARQL 1.2 Query Language, the W3C Working Draft of 19 November 2026 (SPARQL 1.2 is not yet a Recommendation; the draft is pinned so that the changes keep their places). Green is new text and red struck text is removed. Only changes to what a query means or may say are marked; the section numbers of new sections are informal.

rdf-array adds one kind of term to RDF, the sequence, ( 1 2 3 ), and SPARQL-array is SPARQL over it: a collection in a pattern is a sequence pattern with gaps ... and named gaps ...?rest, UNNEST walks a sequence, and expressions index and slice it. The page fetches the draft from w3.org and applies the changes in your browser, so the W3C text is the published one. The design is rdf-array.md and array-syntax.md; the data model is rdf-array.md's, and the OWL-array redline is the same device over the OWL 2 Direct Semantics.
